## 🏛️ Journal Overview

- **Frequency:** Quarterly (4 Issues / Year + Continuous Online Publication)
- **Review Protocol:** Rigorous double-blind peer review (14–21 day initial decision)
- **Licensing:** Creative Commons Attribution 4.0 International (CC BY 4.0) — Authors retain unrestricted copyright
- **Volume 1 Waiver:** 100% APC subsidy (₹0 / ) for all researchers globally
- **Plagiarism Threshold:** Strict <15% similarity limit (excluding bibliography) via Turnitin / iThenticate
- **Indexing Alignment:** UGC-CARE Standards, CSIR-NIScPR, Crossref DOI, Google Scholar, NLM Catalog
